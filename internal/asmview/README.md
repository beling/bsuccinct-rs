`asmview` is an internal BSuccinct library (by Piotr Beling) that contains binary code of selected
functions from other BSuccinct libraries (only `ph` at the moment).
Its sole purpose is to view the (assembly) code generated by the compiler.

## Managing & comparing assembly snapshots (`asm.py`)

`asm.py` allows saving local snapshots, inspecting assembly, watching for live file changes, and quickly comparing generated assembly during iterative optimizations.

Snapshots always store the assembly for **all** functions in `.snapshots/` (ignored by Git).

### Syntax for filtering functions (`[target][:filter]`)

Filtering by function name uses the `:filter` suffix directly in target names:
- `:fn` – function `fn` from `CURRENT` (working directory) or default target.
- `snapshot:fn` – function `fn` from a specific snapshot (e.g. `baseline:phast_get_f2`).
- `git_<ref>:fn` – function `fn` from a Git revision (e.g. `git_main:shift`).

### Using external diff tools (`-t` / `--tool`)

You can specify a custom diff tool program (e.g. `meld`, `kdiff3`, `code --diff`, `diff -u`) using `-t` or `--tool`:

```bash
./asm.py diff -t meld
./asm.py diff :phast_get_f2 -t meld
./asm.py diff :seed_only :shift_only -t meld
./asm.py diff git_main -t "diff -u"
```

### Examples

```bash
# 1. Save current state as baseline snapshot:
./asm.py save

# 2. Compare current state with baseline:
./asm.py diff                      # all functions
./asm.py diff :phast_get_f2        # only functions matching 'phast_get_f2'

# 3. Compare two different functions in current working directory:
./asm.py diff :seed_only :shift_only

# 4. Compare current state with main branch (or previous commit):
./asm.py diff git_main
./asm.py diff git_main :phast_get_f2
./asm.py diff git_HEAD~1 :phast_get_f2

# 5. Save a named snapshot before experimental changes:
./asm.py save unrolled_loop

# 6. Compare two snapshots (or two functions across snapshots):
./asm.py diff unrolled_loop
./asm.py diff baseline unrolled_loop
./asm.py diff baseline unrolled_loop :phast_get_f2
./asm.py diff baseline:seed_only unrolled_loop:shift_only

# 7. Live watch mode (automatically recompiles and diffs on *.rs file save):
./asm.py watch
./asm.py watch :phast_get_f2
./asm.py watch git_main:phast_get_f2

# 8. List saved snapshots and available functions:
./asm.py list

# 9. Show assembly for current code or a snapshot / Git revision:
./asm.py show
./asm.py show :phast_get_f2
./asm.py show git_main:phast_get_f2

# 10. Delete a snapshot:
./asm.py rm unrolled_loop
./asm.py rm git_main
```

## Low-level inspection commands

To manually see the code, use for example:
```bash
cargo asm -p asmview phast_get_f2_shift_only_wrapped_1
```

```bash
cargo build -p asmview --release
objdump -d -M intel target/release/libasmview.a | grep -A 50 "<phast_get_f2_shift_only_wrapped_1>:"
```

```bash
cargo rustc -p asmview --release -- --emit=asm
```
and see `target/release/deps/`
