`asmview` is an internal BSuccinct library (by Piotr Beling) that contains binary code of selected
functions from other BSuccinct libraries (only `ph` at the moment).
Its sole purpose is to view the (assembly) code generated by the compiler.

## Quick workflow for iterative optimization (`asm.py`)

`asm.py` allows saving local snapshots, inspecting assembly, watching for live file changes, and quickly comparing the generated assembly during iterative optimizations without touching Git history. Snapshots are stored locally in `.snapshots/` (ignored by git).

```bash
# 1. Save current state as baseline snapshot
./asm.py save

# 2. Modify Rust code in crates (e.g. ph, bitm), then view the diff:
./asm.py diff

# 3. Save a named snapshot before experimental changes:
./asm.py save unrolled_loop

# 4. Compare current state with a named snapshot (or compare two snapshots):
./asm.py diff unrolled_loop
./asm.py diff baseline unrolled_loop

# 5. Live watch mode (automatically recompiles and diffs on *.rs file save):
./asm.py watch

# 6. List or remove snapshots:
./asm.py list
./asm.py rm unrolled_loop

# 7. Show current assembly for all or filtered functions:
./asm.py show
./asm.py show -f phast_get_f2
```

## Comparing assembly with Git revisions (`compare_asm.py`)

Use `compare_asm.py` to compare the assembly generated by the current working tree against another Git revision (e.g. `main`, `HEAD~1`, or a specific branch/tag):

```bash
# Compare all functions against main
./compare_asm.py

# Compare all functions against HEAD~1
./compare_asm.py HEAD~1

# Compare a specific function against a branch
./compare_asm.py -f phast_get_f2_shift_only_wrapped_1 main
```

## Low-level inspection commands

To manually see the code, use for example:
```bash
cargo asm -p asmview phast_get_f2_shift_only_wrapped_1
```

```bash
cargo build -p asmview --release
objdump -d -M intel target/release/libasmview.a | grep -A 50 "<phast_get_f2_shift_only_wrapped_1>:"
```

```bash
cargo rustc -p asmview --release -- --emit=asm
```
and see `target/release/deps/`
