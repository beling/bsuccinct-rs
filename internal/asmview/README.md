`asmview` is an internal BSuccinct library (by Piotr Beling) that contains binary code of selected
functions from other BSuccinct libraries (only `ph` at the moment).
Its sole purpose is to view the (assembly) code generated by the compiler.

## Managing & comparing assembly snapshots (`asm.py`)

`asm.py` allows saving local snapshots, inspecting assembly, watching for live file changes, and quickly comparing generated assembly during iterative optimizations.

Snapshots always store the assembly for **all** functions. Filtering (`-f` / `--function`) is applied dynamically when viewing or comparing assembly (`show`, `diff`, `watch`).

Snapshots are stored locally in `.snapshots/` (ignored by Git).

### Working with Git revisions (`git_<ref>`)

Names starting with `git_` are automatically resolved to a Git commit hash (`git_<hash>`).
If the snapshot does not exist yet, `asm.py` extracts and builds the assembly from that Git revision via a temporary `git worktree`, saves it to `.snapshots/git_<hash>.asm`, and caches it for future use.

### Examples

```bash
# 1. Save current state as baseline snapshot:
./asm.py save

# 2. Modify Rust code in crates (e.g. ph, bitm), then view the diff:
./asm.py diff
./asm.py diff -f phast_get_f2

# 3. Compare current state with main branch:
./asm.py diff git_main
./asm.py diff git_main -f phast_get_f2

# 4. Compare current state with previous commit:
./asm.py diff git_HEAD~1

# 5. Save a named snapshot before experimental changes:
./asm.py save unrolled_loop

# 6. Compare two snapshots (e.g. baseline vs experiment or git vs experiment):
./asm.py diff unrolled_loop
./asm.py diff baseline unrolled_loop
./asm.py diff git_main unrolled_loop -f phast_get_f2

# 7. Live watch mode (automatically recompiles and diffs on *.rs file save):
./asm.py watch
./asm.py watch git_main -f phast_get_f2

# 8. List saved snapshots:
./asm.py list

# 9. Show assembly for current code or a snapshot / Git revision:
./asm.py show
./asm.py show git_main -f phast_get_f2

# 10. Delete a snapshot:
./asm.py rm unrolled_loop
./asm.py rm git_main
```

## Low-level inspection commands

To manually see the code, use for example:
```bash
cargo asm -p asmview phast_get_f2_shift_only_wrapped_m1
```

```bash
cargo build -p asmview --release
objdump -d -M intel target/release/libasmview.a | grep -A 50 "<phast_get_f2_shift_only_wrapped_m1>:"
```

```bash
cargo rustc -p asmview --release -- --emit=asm
```
and see `target/release/deps/`
